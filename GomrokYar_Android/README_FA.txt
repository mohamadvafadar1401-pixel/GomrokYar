گمرکیار اندروید ـ پروژه آماده ساخت APK از طریق سرویس ابری GitHub Actions

این پروژه، نسخه فعلی GomrokYar_Web_v3 را در یک برنامه اندرویدی آفلاین (WebView) قرار می‌دهد.

ساخت APK بدون داشتن کامپیوتر (با گوشی):
1) در GitHub یک حساب بسازید یا وارد حساب خود شوید.
2) از گزینه New repository یک مخزن جدید بسازید؛ نام پیشنهادی: GomrokYar.
3) فایل ZIP پروژه را از حالت فشرده خارج کنید و محتویات پوشه GomrokYar_Android را در مخزن بارگذاری کنید. پوشه .github نیز باید همراه بقیه فایل‌ها بارگذاری شود.
4) پس از بارگذاری، وارد تب Actions شوید و گردش کار Build GomrokYar APK را انتخاب کنید.
5) روی Run workflow بزنید و منتظر سبز شدن اجرای کار بمانید.
6) وارد اجرای موفق شوید؛ در بخش Artifacts فایل GomrokYar-debug-APK را دانلود کنید.
7) ZIP دانلودشده را باز کنید؛ فایل app-debug.apk داخل آن است. آن را برای نیروها ارسال کنید.

مشخصات و نکات:
- برنامه و فایل HTML داخل APK قرار دارند و برای اجرای بخش‌های اصلی نیاز به اینترنت ندارد.
- اطلاعات IndexedDB در حافظه خصوصی همان گوشی ذخیره می‌شود؛ اطلاعات گوشی‌های مختلف خودکار با هم مشترک نیست.
- این خروجی Debug برای نصب و آزمایش مناسب است. برای انتشار سازمانی گسترده، بهتر است نسخه Release امضاشده تهیه شود.
- پیش از استفاده عملیاتی، دوربین/انتخاب عکس، ثبت سوابق و بازیابی پشتیبان را روی مدل گوشی‌های نیروها آزمایش کنید.
- ساخت APK در این روش روی سرور ابری GitHub انجام می‌شود؛ نیازی به نصب Android Studio روی گوشی شما نیست.
